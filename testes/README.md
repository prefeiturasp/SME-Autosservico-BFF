# Testes E2E

Pasta reservada para testes ponta a ponta (E2E) / smoke tests com
[Cypress](https://docs.cypress.io/), [Postman](https://learning.postman.com/docs/)
ou [BDD](https://cucumber.io/docs/bdd/), conforme o padrão SME.

Testes unitários **não** ficam aqui — eles residem dentro de cada app, em
`apps/<dominio>/tests/`.

Nenhuma suíte E2E foi configurada ainda para este serviço.
